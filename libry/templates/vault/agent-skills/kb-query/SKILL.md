# kb-query — 基于知识库的问答

## 流程

1. **查索引**：读 `index.md`，按问题关键词定位候选页面（也可用本地搜索引擎如 `qmd`，若已安装）。
2. **读页面**：读相关 wiki 页面；页面不够时按 `sources:` 元数据回溯 `raw/` 原始资料。
3. **综合作答**：结论先行；引用出处一律用 `[[wikilink]]`（页面标题），并注明该结论来自哪份来源页。多页信息冲突时如实呈现两边并指出矛盾点。
4. **沉淀成果（有价值的副产品）**：如果这次回答产生了有价值的对比/分析/新关联，主动提议存为 `wiki/synthesis/` 新页面——**先给提纲征得用户同意**，再写页面（frontmatter + 合适分类的 index.md 条目 + wiki/log.md 记录）。

## 惯例

- 回答依赖 wiki 的健康度；若发现断链/过期内容，顺手提议跑 `kb-lint`。
- 知识库没有答案的部分如实说「库里没有」，需要外部搜索时先问用户。
- 个人文档（visibility: personal）的内容不要泄露进共享语境的回答。
